

스마트 코드 입력 수정
- Python / Linux / React 실습실 공통 적용
- Tab: 공백 4칸 입력
- Shift+Tab: 들여쓰기 한 단계 제거
- Enter: 현재 줄의 들여쓰기 자동 유지
- Python에서 ':' 뒤 Enter: 자동으로 4칸 추가 들여쓰기
- React/JS/CSS에서 '{' 뒤 Enter: 자동으로 4칸 추가 들여쓰기
- Bash에서 then / do / '{' 뒤 Enter: 자동으로 4칸 추가 들여쓰기
- Ctrl+Enter 정답 제출 기능 유지


이번 수정 핵심
1. 사라졌던 questions.js / linux-questions.js / react-questions.js를 ZIP에 복구했습니다.
2. 총 문제 수: Python 1,400 + Linux 1,400 + React 1,400 = 4,200.
3. 반복이 특히 심했던 Linux 패키지/환경변수, React 시작/State/Event/조건부/리스트/Effect/라우팅/설계/프로젝트 단계는 문제 구성을 새로 만들었습니다.
4. 랜덤 20문제는 문제 계열과 난이도를 섞는 방식으로 변경했습니다.
5. Python은 가능한 문제에서 실행 결과 기반 의미 판정을 사용합니다(Pyodide, 인터넷 연결 시).
6. 실행 판정이 적합하지 않은 문제는 기존 구조 판정 + 여러 대체 정답으로 처리합니다.
7. Linux/React도 의미 없는 공백/따옴표/세미콜론과 일부 동등 표현을 추가 허용합니다.
8. 자동 들여쓰기(Tab 4칸, Enter 후 블록 들여쓰기)는 유지합니다.
9. quality-report.html에서 단계별 검수 결과를 확인할 수 있습니다.
